🤖 AI Smart Campus Management System

An AI-powered web application designed to automate and enhance campus operations like attendance, timetable, notifications, and student support using intelligent systems.

🚀 Features
🤖 AI Chatbot (IMS Bot)
Answers student/faculty queries instantly
Uses NLP (Natural Language Processing)
Example: “When is my exam?” → instant reply
📅 Smart Timetable Generator
Generates conflict-free schedules
Considers faculty availability, rooms, and subjects
📊 Attendance Prediction System
Tracks attendance automatically
Predicts shortage using AI
Sends alerts to students
🧾 Exam Seating Optimization
Allocates seating using algorithms
Avoids overcrowding and ensures fairness
👨‍🏫 Smart Invigilator Allocation
Assigns duties based on workload and availability
🔔 Smart Notification System
Sends alerts for exams, assignments, and events
Personalized notifications
📈 Role-Based Dashboard
Separate views for Admin / Faculty / Students
Displays analytics, reports, and tasks
📧 AI Email Task Extractor
Converts emails into task lists
Automatically assigns priority
🔐 Cybersecurity Layer
Detects suspicious login/activity
Protects sensitive data
